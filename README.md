UiPath Training:

This repository contains UiPath Studio workflows covering foundational automation concepts, control flow logic, and inter-workflow data passing.

DAY 1:

->Basics, Arithmetic, and Arguments

*Main.xaml: Main entry point workflow.  
*username.xaml & Concatenate.xaml: Basic input handling and string manipulation.  
*Sum.xaml, Sub.xaml, mutiply.xaml: Basic arithmetic operations.  
*Pass a Number.../: Demonstrates passing numeric arguments between workflow8_1.xaml and workflow8_2.xaml.  
*Pass a Name.../: Demonstrates passing string arguments between workflow9_1.xaml and workflow9_2.xaml.  
*Employee Salary Calculation.../: Practical example of multi-workflow data processing (Workflow10_1.xaml and Workflow10_2.xaml). 



DAY 2:

->Control Flow & Data Validation

*If.xaml: Basic single-condition execution.  
*If Else.xaml: Binary branching (True/False paths).  
*Else if.xaml: Multi-condition sequential evaluation.  
*employee validation.xaml: Applied conditional logic for validating employee records.
